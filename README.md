# Monitoramento IA

Sistema de monitoramento inteligente baseado em visão computacional.

## Objetivos

- Consumir streams RTSP
- Detectar eventos
- Reconhecer pessoas recorrentes
- OCR de placas
- Dashboard Web
- API REST
- Banco de eventos

## Hardware

- Reolink Duo 2 WiFi
- TP-Link TL-SG108PE
